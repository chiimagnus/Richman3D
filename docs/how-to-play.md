# 怎么玩 Richman 3D

在主菜单点击「开始游戏」，选择2–4席，设置名字和对局长度，再点击「开始对局」。本阶段支持一名本地玩家对1–3名普通电脑，尚未开放多真人；留空使用可随语言切换的默认名，自定义名字不翻译。名字去掉首尾空白，最多16个可见字符。更多选项中可选择棋子颜色。

主菜单和局内均有「怎么玩」，可在游戏中直接阅读当前已实现规则。英文说明见 [How to play](how-to-play.en.md)。

## 独立实操教学

主菜单的「实操教学」使用固定种子的独立真实练习局，依次看资金、掷骰、查看落点、选择购买或跳过、观察电脑行动，共五步。提示只附在当前行动区，不会伪造购买。可以任一步点击「跳过教学」，或用 Tab 聚焦该按钮后按 Enter。

教学中切换语言或查看帮助保留当前进度；完成后回到新对局配置。正式局重新生成种子，资金和地产均不继承教学。只有真正完成五步才保存独立的教学完成标记；教学不替换正式局存档、不记战绩。之后可通过「重看教学」再次练习。

## 游戏目标

各席都从起点出发，初始资金为 1500。开局由规则种子确定一次固定轮序，保存在局面中，暂停菜单可查看；恢复不重新洗牌，姓名、颜色和配置顺序不决定先手。

默认快速模式20整轮，也可选标准40整轮；一轮是固定轮序走过一次，破产席跳过，不改变原轮序边界。最后一位存活玩家的购买决定完成，并跨过原尾席后才计入轮数。

一方资金低于0时立即破产，唯一未破产者提前获胜。达到轮数上限则按净资产（现金加所持地产标价）排名，再按现金比较；仍相同则并列获胜。当前没有债务周转、建筑、拍卖、交易或持有道具。

## 一个回合怎么进行

1. 点击底部的「掷骰子」，或按 `Space`。
2. 游戏掷两颗骰子，并自动按总点数移动。
3. 到达地块后立即结算对应事件。
4. 如果你停在无主地产上，可以选择购买或跳过。
5. 回合按开局固定轮序切换；电脑玩家自动完成自己的回合。

不需要手动控制角色沿棋盘走动。掷骰、落地、资金变化和回合切换都会自动显示对应反馈。

## 不同地块会发生什么

### 地产

- **无主地产**：资金足够时可以购买，也可以跳过。
- **自己的地产**：不会产生额外费用。
- **对手的地产**：自动向对方支付该地产的租金。

购买后的地产会在 3D 棋盘上显示归属标记。

### 起点

每次**经过起点**会获得 200。

### 机会

立即抽取一个随机事件，可能增加或减少资金。

### 税收

立即支付地块标明的费用。

## 第一人称视角

桌面默认本人第一人称，不自动申请鼠标锁定；「棋盘总览」可以查看完整棋盘和各席棋子，再点击「本人第一人称」返回自己的位置。总览不改变规则或骰子，停用鼠标锁定。触屏默认总览，所有行动均可用屏幕按钮完成；当前总览没有拖拽、缩放或点选地产。

点击「环视」按钮可以进入第一人称环视，不会自动锁定鼠标。

进入后移动鼠标即可观察四周；按 `Esc` 退出环视。

第一人称模式会锁定鼠标；按 `Esc` 退出后可继续操作按钮，也可以使用快捷键。角色移动仍由棋盘规则控制，没有 `WASD` 自由移动。

## 设置

点击右上角「设置」可以调整：

- **声音**：开启或关闭游戏音效。
- **鼠标灵敏度**：低、标准、高三档，只影响第一人称环视。
- **语言**：在中文与 English 之间切换，界面、反馈提示和 3D 棋盘文字会同步更新。

设置会保存在当前浏览器中；存储被拒绝时本局仍可调整设置。可以按 `M` 开关声音，或按 `Esc` 退出环视后再操作设置。设置期间对局暂停；点击「完成」或按 Esc 关闭面板时焦点返回设置入口，不自动申请鼠标锁定。

切换到后台时对局暂停，画面直接显示已结算结果，不重新付款或掷骰。回来后点击暂停菜单的「继续」。演出完成前不能输入下一步行动。

主菜单可先切换语言和设置，未开局不创建 3D 场景或音频上下文。局内点击「暂停」可继续、重开或返回菜单。浏览器拒绝声音时仍可玩，可在设置中关闭再开启声音重试。

## 本地保存与续玩

正式局创建及每个被接受的行动在演出前自动保存已提交的局面；返回菜单先等待保存，之后可点「继续已保存对局」。刷新后从最后一次成功保存的位置、资金、产权、决策和随机状态恢复，不重扣钱或补发起点奖励。电脑待行动也须先由你点击继续。已结束局显示「查看已保存结算」，不是新回合。

切到后台会暂停，并把当前动画收敛到已结算位置，不保存动画帧。回到前台仍保持暂停，需要明确点击继续；读档期间切到后台，也不会趁加载完成擅自推进电脑。

本地只保存当前局与前一有效快照，重开或开始新局会替换当前局。保存失败时可「重试保存」或「继续但不保存」；重试不重新执行行动，不保存状态持续可见。另一页面已更改存档时，本页暂停，可明确载入最新存档或放弃本页未保存进度，不能静默覆盖。坏档和不认识的版本保留原数据，不自动清空。

存档仅在同一浏览器、配置和站点内可用，不是云备份；浏览器清理、私密模式、设备故障可能丢失本地数据。暂停菜单和保存问题面板可以「导出对局文件」，即使浏览器拒绝保存仍可导出当前内存局面为`.richman.json`。文件含名字与完整局面，分享前注意隐私。

在主菜单、暂停或保存问题面板打开「导入与恢复存档」，选择不超过 1 MiB 的文件。完整检查格式、版本和局面后先预览保存时间，只有点击「确认替换存档」才替换当前局，包括本页未保存进度。取消或校验失败不会销毁当前对局。导入局标记为导入来源，不作为正式挑战成绩；这个标记不是反作弊证明。

也可预览「上一有效备份」，核对原保存时间后确认恢复。恢复与导入后返回菜单，须再次点击继续才推进电脑。未知版本和坏档不会自动清空或回退；先用「导出当前原始数据」保留副本，再明确决定是否替换。无有效备份时不能凭空恢复。确认前其他页面改动了存档，替换会被拒绝，须重新读取预览；不自动抢写。

## 快捷键

| 操作 | 按键 |
| --- | --- |
| 掷骰子 | `Space` |
| 购买当前地产 | `B` |
| 跳过当前地产 | `N` |
| 开关声音 | `M` |
| 退出第一人称环视 | `Esc` |
| 未锁定且没有面板时打开暂停 | `Esc` |

`B` 和 `N` 只在轮到你处理地产购买时生效。

## 怎么看界面

- **左上**：各席名字、当前资金和轮次。
- **右上**：设置、帮助、暂停与镜头入口。
- **底部**：你所在的地块、最近一次骰子点数和当前可执行操作。
- **画面中央**：骰子结果和需要说明的落地事件短暂出现；购买结果不再重复叠加提示。

底部显示当前行动者的地块；落地时更新已结算资金并说明原因，短暂等待反馈后电脑才行动，期间不能输入下一动作。可以点击「跳过动画」直接显示已结算结果。关闭声音立即停止当前音效，不影响视觉反馈和游戏规则。

## 游戏结束

租金、税收或机会事件都可能让资金跌破 0。破产只淘汰该席，其地产归还银行，不再收租；历史购地支出仍保留在财务明细。剩余多席继续对局，唯一未破产者才提前获胜。本人淘汰后可继续观看，或从暂停菜单返回主菜单。「跳过动画」仅加快演出，不代替规则结算。

结算第一屏显示赢家（包括并列）、结束原因、你的名次及净资产排名。展开「财务明细与重玩」查看最终现金、地产账面价值、起点奖励、租金收支、费用、机会和购地支出。这些统计由已提交的真实规则结果记账，动画、跳过或切语言不会重复累计。

点击「再来一局」以相同名字、颜色和局长、不同种子重新开始，无须刷新网页。明细中的「重玩原种子」以同一个种子重新开始，选择不同可能改变结果。当前没有永久战绩；返回菜单不会声称已保存胜场。离开对局会释放场景并停止本局音符，应用复用一个音频上下文。
