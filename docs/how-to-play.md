# 怎么玩 Richman 3D

在首屏点击「开始游戏」，开始你与电脑玩家「城市玩家」之间的 1v1 大富翁。

## 游戏目标

双方都从起点出发，初始资金为 1500。

**让对手先破产即可获胜。** 当玩家资金低于 0 时立即破产，游戏结束。

## 一个回合怎么进行

1. 点击底部的「掷骰子」，或按 `Space`。
2. 游戏掷两颗骰子，并自动按总点数移动。
3. 到达地块后立即结算对应事件。
4. 如果你停在无主地产上，可以选择购买或跳过。
5. 你的回合结束后，电脑玩家会自动完成自己的回合。

不需要手动控制角色沿棋盘走动。掷骰、落地、资金变化和回合切换都会自动显示对应反馈。

## 不同地块会发生什么

### 地产

- **无主地产**：资金足够时可以购买，也可以跳过。
- **自己的地产**：不会产生额外费用。
- **对手的地产**：自动向对方支付该地产的租金。

购买后的地产会在 3D 棋盘上显示归属标记。

### 起点

每次**经过起点**会获得 200。

### 机会

立即抽取一个随机事件，可能增加或减少资金。

### 税收

立即支付地块标明的费用。

## 第一人称视角

点击「环视」按钮可以进入第一人称环视，不会自动锁定鼠标。

进入后移动鼠标即可观察四周；按 `Esc` 退出环视。

第一人称模式会锁定鼠标；按 `Esc` 退出后可继续操作按钮，也可以使用快捷键。角色移动仍由棋盘规则控制，没有 `WASD` 自由移动。

## 设置

点击右上角「设置」可以调整：

- **声音**：开启或关闭游戏音效。
- **鼠标灵敏度**：低、标准、高三档，只影响第一人称环视。
- **语言**：在中文与 English 之间切换，界面、反馈提示和 3D 棋盘文字会同步更新。

设置会保存在当前浏览器中；存储被拒绝时本局仍可调整设置。可以按 `M` 开关声音，或按 `Esc` 退出环视后打开设置。设置期间对局暂停；关闭面板时焦点返回设置入口，不自动申请鼠标锁定。

切换到后台时对局暂停，画面直接显示已结算结果，不重新付款或掷骰。回来后在设置中点击「返回游戏」继续。演出完成前不能输入下一步行动。

## 快捷键

| 操作 | 按键 |
| --- | --- |
| 掷骰子 | `Space` |
| 购买当前地产 | `B` |
| 跳过当前地产 | `N` |
| 开关声音 | `M` |
| 退出第一人称环视 | `Esc` |

`B` 和 `N` 只在轮到你处理地产购买时生效。

## 怎么看界面

- **左上**：双方当前资金。
- **右上**：设置入口。
- **底部**：你所在的地块、最近一次骰子点数和当前可执行操作。
- **画面中央**：骰子结果和需要说明的落地事件短暂出现；购买结果不再重复叠加提示。

底部显示当前行动者的地块；演出结束后才切换决策和资金。可以点击「跳过动画」直接显示已结算结果。关闭声音立即停止当前音效，不影响视觉反馈和游戏规则。

## 游戏结束

租金、税收或机会事件都可能让资金跌破 0。发生破产后，另一名玩家立即获胜。

结算画面会显示胜负结果。点击「再来一局」即可重新开始，无须刷新网页。也可返回主菜单；离开对局会释放场景和音频资源。
